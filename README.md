# Lamppost Web Studios

Lamppost Web Studios is a web design and solutions agency helping small businesses build polished, effective online presences.

## Tech Stack

- Svelte 5 and SvelteKit
- TypeScript
- Vite
- Iconify with Gravity UI Icons

## Development

```sh
pnpm dev
```

Run checks with `pnpm check` and create a production build with `pnpm build`.

## Icons

Browse the installed Gravity UI Icons set at [https://icon-sets.iconify.design/](https://icon-sets.iconify.design/?query=sun&search-prefix=gravity-ui).
